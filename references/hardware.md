# 真机硬件（hardware）

> 轻量穿戴设备按型号/代号区分圆屏或方屏，屏幕分辨率与传感器硬件能力（加速度计、心率、振动等）影响布局与功能设计。开发前先建立目标设备档案，不得以 512 KB heap 或最高分辨率当作全系列下限。

## 设备档案

在写代码前明确并记录以下字段（评审模板见 [评审输出要求](project-reviewer.md#输出解读)）：

| 字段 | 说明 |
|---|---|
| 型号/代号 | 例如 WATCH GT2、GT3、GT3 Pro、FIT3、FIT2、D2 等；区分营销型号与具体代号/固件 |
| 圆屏或方屏 | GT 系列为圆屏，FIT 系列与 D 系列为方屏 |
| 物理分辨率 | 屏幕固有像素，用于核对素材清晰度 |
| 适配分辨率 | 开发时按此基准布局，优先于物理分辨率 |
| 固件 | 记录实测固件版本 |
| JS heap 档位 | 64 / 256 / 512 KB，见 [真机系统](system.md#js-heap-档位) |
| API 版本 | target / compatible / deviceInfo 三者不是同一字段，见 [真机系统](system.md#api-版本) |
| WearEngine 版本 | 决定可用特性 |
| 所需硬件能力 | 加速度计、心率、振动等 |

如果用户未指定型号，默认按最差档处理：64 KB JS heap、旧版 API、圆屏安全区；同时把最终兼容范围标为"待真机确认"。

## 屏幕与适配分辨率

设备矩阵来自社区实测经验，发布前以目标真机、当前固件和可合法访问的官方资料复核：

| 设备组 | 屏幕 | 物理分辨率 |
|---|---|---|
| GT3/GT4/GT5/GT6、Runner/Ultimate 多数圆表 | 圆 | 466x466 |
| GT2 42mm | 圆 | 390x390 |
| GT2 46mm、GT2e、GT2Pro、GS3、GSPro | 圆 | 454x454 |
| FIT5 Pro、FIT5、FIT4 Pro、FIT4、FIT3 | 方 | 408x480 |
| FIT2 | 方 | 336x480 |
| D2 | 方 | 408x480 |
| D | 方 | 280x456 |

不要根据物理分辨率直接写死 UI。优先按适配分辨率布局，再核对对应物理像素素材。

## 屏幕适配

- **圆屏安全区**：把关键信息、按钮和滚动区域放入安全区，边缘仅承载可裁切背景。
- **边缘裁切**：核对最长中文文本、系统字号、列表滚动、点击/长按/滑动冲突、状态栏/表冠区域和屏幕边缘裁切。
- **多分辨率兼容**：不得仅在 466x466 模拟器上通过后宣称兼容 390x390、454x454、408x480、336x480 或 280x456。若宣称跨代兼容，至少覆盖最低 heap/API/分辨率档，不能只测最高端型号。
- **布局方式**：优先稳定的固定基准尺寸配合百分比布局；方屏与圆屏分支要显式、有限并可测试。CSS 样式特性（仅 flex/stack、px 与百分比单位等）见 [viewmodel-style.md](viewmodel-style.md#css-样式特性)。

## 传感器硬件能力

轻量穿戴通过 `@system.*` 模块访问传感器，全部为异步回调模式，参数与限制见 [system-api.md](system-api.md)：

- **加速度计**：`@system.sensor` 的 `subscribeAccelerometer`，返回 `{ x, y, z }`。只有订阅没有取消订阅，需按页面生命周期受控回收。
- **心率**：`@system.sensor` 的 `subscribeHeartRate`，返回 `{ heartRate }`。
- **振动**：`@system.vibrator` 的 `vibrate`，`mode: 'short' | 'long'`。
- 其他：亮度（`@system.brightness`）、电量（`@system.battery`）、定位（`@system.geolocation`）等。

传感器默认使用最低可接受频率，不能为了 UI 每帧刷新而使用 `game` 频率。模拟器不能证明真实传感器行为，必须在真机验证。

## 硬件不确定性

- 型号相似不代表 heap 相同，例如 GT3 与 GT3 Pro 已出现 256/512 KB 差异，见 [真机系统](system.md#js-heap-档位)。
- 固件升级可能改变 `deviceInfo` 返回值、接口行为或构建目标，但不能假设会扩大物理内存。
- 发布矩阵应记录具体代号、固件和实测结果，不只记录营销型号。
- 资料中带不确定标记的字段只能作为待验证信息，不能据此生成绝对兼容声明。
